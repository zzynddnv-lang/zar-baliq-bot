# ZAR BALIQ - Telegram Restoran Boti 🐟🥟

«ZAR BALIQ» restorani uchun maxsus Telegram bot.

## Imkoniyatlar:
- 🐟 Baliq taomlari menyusi
- 🥟 Somsa turlari menyusi
- 📞 Buyurtma va yetkazib berish xizmati bilan bog'lanish
- 📍 Restoran manzili va ish vaqti

## O'rnatish va ishga tushirish:
```bash
pip install -r requirements.txt
python bot.py
```
